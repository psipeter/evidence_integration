% STRUCTURE. "General concerns" (C1-C4) restates the reviewers' and editor's
% core concerns IN THEIR TERMS, concedes each, and shows the manuscript text
% and figures that address it. The per-comment replies under Reviewer 1 and
% Reviewer 2 then do the same again for each specific comment.
%
% Rules that shaped the current structure, worth keeping if it is edited:
%
%   - DUPLICATE RATHER THAN CROSS-REFERENCE. Wherever a reply would otherwise
%     say "see C3" or "see our response to 1.7", paste the material again
%     instead. The reviewer must see what answers their question immediately
%     after we restate it, without turning to another part of this letter or
%     opening the manuscript. The General concerns section is read mainly by
%     the editor; R1 and R2 read their own sections. Material therefore
%     appears two or three times BY DESIGN -- that is not redundancy to be
%     cleaned up later. (Alireza's house style; the exemplar is Farashahi &
%     Soltani's 2021 rebuttal, which re-presents the same figure under a new
%     local number in a second reviewer's section rather than pointing across.)
%     Cross-referencing INTO the Supplement is fine, and so is a pointer
%     between C-sections, since the editor reads those continuously.
%
%   - PASTE THE MANUSCRIPT'S OWN TEXT AND FIGURES, don't describe them. Show
%     the actual caption, passage or figure that answers the comment, not a
%     summary of it. Abridge freely, but do not paraphrase into new prose that
%     then has to be kept true to the manuscript.
%
%   - PASTED MANUSCRIPT TEXT comes in TWO LAYERS, each with its own colour:
%       PROSE    msblue (navy) + \small, inside \begin{ms}...\end{ms}
%       EXHIBITS mscap (teal) + \scriptsize -- figure captions, table
%                captions, and table bodies
%     The split exists for PAGE BREAKS. A caption continuing onto a new page
%     has no figure and no bold "Figure N." lead-in in view, so it must be
%     identifiable on its own; two pages currently open mid-caption. Size
%     alone was tried first (\small vs \footnotesize, a 1pt difference) and
%     was too subtle to carry it, hence the separate hue.
%     A bracketed \textit{[from Discussion: ...]} insert stays msblue \small:
%     it belongs to the prose layer, not the exhibit layer. No
%     indentation: figures and tables cannot be indented to match, so an
%     indent-based scheme was visibly inconsistent exactly where the pasted
%     material was most prominent. Colour alone carries the distinction, and
%     it survives a page break mid-block, which indentation does too but
%     \small alone would not.
%
%   - TWO STANDARDS OF QUOTING, BY SECTION. The rules immediately below are
%     written for R1 and R2, where a reviewer may check our quotation against
%     the manuscript line by line, and are followed strictly there.
%
%     C1-C4 ARE DELIBERATELY LESS RIGOROUS. They are a condensed brief for the
%     editor, not a quotation record, and they relax the rules in two named
%     ways:
%       (a) a block may carry a numbered heading of OUR OWN (C2.1, C2.2)
%           naming the argument rather than the manuscript section;
%       (b) a block may run text from two different sections together, joined
%           by \textit{[\ldots]}, where strictly that marker means an omission
%           WITHIN one source. C2.1 and C2.2 both do this: Results prose runs
%           into the matching Discussion paragraph's mechanism and test
%           sentences.
%       Interior sentence-level abridgement behind \textit{[\ldots]} is used
%       much more heavily in C1-C4 than in R1/R2 -- C3.1 and C3.2 are abridged
%       inside almost every paragraph. That is permitted in both sections (the
%       marker is visible and claims only that something was cut), but the
%       DENSITY of it in C1-C4 is part of what makes them a brief rather than
%       a quotation record.
%     Nothing false is asserted -- [\ldots] claims only that something was cut
%     -- but a reader cannot reconstruct the source boundaries from C1-C4, and
%     should not be expected to. The fuller versions are in R1 and R2, which
%     the editor also reads.
%
%     DO NOT propagate (a) or (b) into R1/R2.
%
%   - BLOCKS CARRY NO SOURCE LABEL, ANYWHERE IN THE LETTER. Earlier drafts
%     gave every \begin{ms} block a bold heading naming the manuscript
%     section it came from ("Results: <title>", "(excerpt)" for a slice).
%     Those were all removed on 2026-10-18 and the practice is discontinued.
%     Blue is the cue that the text is the manuscript's own; OUR OWN PROSE
%     IMMEDIATELY ABOVE each block is what says where it comes from and why
%     it is there, so that lead-in sentence is now load-bearing -- never
%     open a block without one.
%     The old rule "never merge text from two sections into one block" also
%     went with the labels: with nothing asserting a single source, a block
%     may run two passages together behind a visible \textit{[\ldots]}
%     anywhere in the letter, not only in C1-C4.
%     What has NOT changed: every slice is contiguous in the manuscript, and
%     an interior gap is ALWAYS marked. Dropping the labels removes a claim
%     about WHERE text came from; it does not license altering the text.
%   - BRACKETED INSERTS carry material from a DIFFERENT part of the manuscript
%     into a pasted block, set as \textit{[from Discussion: ...]} -- italic,
%     with literal square brackets, inside the surrounding blue. Used in C2 to
%     append each prediction's mechanism and test protocol to the Results
%     paragraph reporting it, which the Results alone do not state.
%
%     An insert is a CONTIGUOUS slice of its source paragraph. It may begin
%     late (the Results already state the prediction, so each C2 insert starts
%     at the mechanism sentence) and it may stop early. It may also skip
%     material in the middle, but ONLY behind a visible \textit{[\ldots]}:
%     an UNMARKED gap inside something presented as a quotation is the exact
%     misrepresentation these rules exist to prevent. An earlier draft of C2's
%     fourth insert jumped from the test sentence to a converging-evidence
%     citation, silently dropping the passage between them -- that is the
%     thing to avoid, not the omission itself.
%
%     (An earlier version of this rule explained when to label a block
%     "(excerpt)". Labels are gone, so the question no longer arises; the
%     [\ldots] is now the only signal, which is why it must never be
%     omitted.)
%
%     Prefer the WHOLE section where you can. Excerpting costs more than it
%     saves: it can break a reference the kept text depends on (an early C3
%     draft dropped the paragraph naming the plausibility criteria that the
%     next paragraph opens by referring back to), it shifts load onto our own
%     voice, and it invites the reader to wonder what was left out.
%
%   - TODO reviewer quotes are to become NON-ITALIC RED, replacing the italic
%     treatment below. That also removes the one collision in the current
%     scheme: bracketed inserts are italic too, and once R1/R2 are converted a
%     blue italic insert could sit near a black italic reviewer quote.
%
%   - A CAPTION CANNOT CARRY WHAT THE PROSE ABOVE IT NEEDS. Within a section
%     the quoted prose is read BEFORE its figure, so motivation, task names
%     and measure definitions must appear in the quoted text or in our own
%     paragraph -- never deferred to the caption below. A caption may only
%     carry material REDUNDANT with the prose, not prerequisite to it.
%     This blocks an otherwise tempting cut: Fig 6's caption states every

%     cutting its openings would leave the reader meeting "activity decay:

%     task was simulated, until further down the page. C2.1 and C2.2 are
%     therefore quoted in full. C1 is not a counterexample: the paragraph cut
%     there was followed by no prose depending on it, and the first mention
%     of Mean/LI/PR is the figure itself with its caption directly beneath.
%
%   - NO MACROS, NO FLOATS. Paste plain LaTeX inline: \begin{center}
%     \includegraphics{figures/<stem>.pdf} \end{center} followed by
%     {\small\textbf{Figure~\ref{<label>}.} <pasted caption>\par}. Floats would
%     renumber from 1 and collide with the manuscript numbers \ref pulls from
%     main.aux, and would drift away from the comment they answer. Wrap a
%     table's caption and its tabular together in a \begin{minipage}{\textwidth}
%     or LaTeX will break the page between them.
%
%   - WHEN PASTING, rewrite main.tex's \cite{} as \citep{}: main.tex uses
%     scicite (numeric superscripts), this file uses natbib/apalike, where a
%     bare \cite is the TEXTUAL form and renders "...no free parameters
%     DeGroot (1974)".
%
%   - PASTED PROSE IS COPIED, NOT LINKED. If main.tex's wording changes, the
%     excerpts here go stale silently. Re-check every pasted block against
%     main.tex before the final build. (Only the NUMBERS are live, via xr.)
%
%   - ECHO THE POSITIVE COMMENTS. Both reviewers opened approvingly and
%     several individual comments concede something before objecting. Quote
%     that praise where it is relevant, not only once per reviewer.
%
%   - REVIEWER TEXT IS ALWAYS RED AND UPRIGHT, wherever it appears. \rc's
%     second argument does this automatically; a standalone quote needs
%     {\small\color{revred}``...''} by hand. (Quotations that are NOT reviewer
%     text -- Yoo et al.'s paper in 1.1, our own scare quotes -- stay black.)
%     It was italic until the per-comment sections were built; red frees
%     italic for bracketed inserts, which would otherwise have sat a few lines
%     from an italic reviewer quote inside R1/R2 with only colour to tell them
%     apart.
%
%   - NO DIRECT REVIEWER QUOTES IN C1-C4. The General concerns section states
%     the concerns in our own words; quoting is saved for R1/R2, where each
%     comment is quoted at the point it is answered.
%
%   - ABRIDGE the quoted comments to the sentence(s) the response answers, but
%     always QUOTE rather than paraphrase: the editor reads this against the
%     original review.
%
%   - OBVIOUS TYPOS IN REVIEWER TEXT ARE CORRECTED SILENTLY, never marked
%     [sic] -- [sic] on a reviewer reads as point-scoring. Two so far: R1's
%     "missfits" -> "misfits" (1.5) and R2's "specific biologically
%     properties" -> "biological" (R2 header). A quote checker against
%     Downloads/old_paper/old_paper_review.pdf will flag both, plus
%     "well-established", which only differs because pdftotext hyphenated it
%     across a line break in the source. Those three are the expected
%     mismatches; anything else is a real divergence.
%
%   - Abbreviations are defined at first use and the opening paragraph has
%     none. The network is "SNN" throughout, never "our network".
%
%   - Present tense for results and model behavior; past tense only for
%     actions we took (designed, collected, renamed, removed).

\subsection*{Criticism 3: The case for our neural network as an advance over existing mathematical and recurrent neural network models was underdeveloped}

Both reviewers questioned whether DPE represents a genuine advance. Reviewer~1 noted that neither reinforcement learning nor the idea of learning rates that decline with experience is new, and that it was unclear what our model adds to those existing accounts. Reviewer~2 raised the same concern from a different direction, observing that DPE is one instance of an established class of models that use weighted updating. We accept both premises. Dynamic weighting of past evidence has a long history, and we no longer claim novelty on that basis. Our claim is narrower: among the models in this family, DPE is simple enough to be computed by a brain in real time, and to our knowledge it is the only one that has actually been realized in a spiking circuit, built with the Neural Engineering Framework (NEF), and tested against human behavior. The Discussion now makes these comparisons explicit, first against existing mathematical models and then against the recurrent neural networks typically fit to behavioral data. We summarize both here, and expand each in our point-by-point replies to Reviewers~1 and~2 below.

\subsubsection*{C3.1 Comparison against existing mathematical models}

\begin{ms}

\textit{[\ldots]} What makes a model a plausible candidate for the brain's actual mechanism, rather than a redescription of its output, is whether its weighting of past evidence could reasonably be computed by the brain in real time. Numerous factors contribute to a model's neural plausibility, including its memory requirements, the number and complexity of the operations it performs, and whether its biases emerge from its mechanisms or are embedded in them by design. We argue that DPE meets all these criteria, whereas competing models fail at least one.

DPE belongs to a family of models that compress the influence of all past observations into a single estimate that is carried forward in time and updated via a weighted prediction error (PE; Eq.~\ref{eq:dpe_update}). These models differ primarily in how the weight on the newest observation, $\alpha(n)$, is computed. \textit{[\ldots]} In every member of this family, bias is a byproduct of an otherwise generic attempt to track an uncertain, dynamic, or imprecisely-remembered world, not a pattern the model was built in advance to reproduce. \textit{[\ldots]} This kind of imprecise, approximate discounting with more observations is a reasonable computational constraint for a biological system \textit{[\ldots]}

Competing models fail neural plausibility standards in different ways. PR's weight for each past observation must be recomputed across the entire raw history whenever a new observation arrives, requiring an expanding memory of all previous observations alongside an expensive weighted summation \textit{[\ldots]} this mechanism serves as a flexible measurement of an already-observed bias, in the same spirit as other descriptive weighting methods that recover a temporal profile without proposing how it could be computed online \citep{anderson1965primacy, levi2018strategic, okazawa2018psychophysical}. Similarly, the Experience-Weighted Attraction (EWA) model \citep{camerer1999experience, ho2007selftuning} was developed for repeated strategic interaction \textit{[\ldots]} [and] requires maintaining a memory of each strategy's attraction and foregone payoff, as well as a parallel computation across alternatives to select a response. \textit{[\ldots]} It is telling that, to our knowledge, none of these models has actually been realized in a neural circuit. In contrast, DPE's running estimate requires neither unbounded memory nor involved calculations, and its biases emerge rather than being assumed. Being neurally implementable is therefore not a side benefit of DPE's simplicity, but the main reason it fits the criteria laid out above.

\textit{[\ldots]} DPE closely matched human behavior across all four tasks studied here, and generally outperformed other baseline models \textit{[\ldots]} DPE is a deliberately-simple starting point, not a ceiling on what dynamic PE models can achieve. Critically, because the core neural network responsible for the PE update is agnostic about how $\alpha(n)$ is computed, additional neural populations could be added alongside the existing error circuitry, allowing the SNN to implement more sophisticated, data-driven modulation by $\alpha(n)$. \textit{[\ldots]} Taken together, these features -- performance, scalability, heterogeneity, and extensibility -- make DPE a compelling account of the cognitive processes underlying evidence integration.
\end{ms}

\subsubsection*{C3.2 Comparison against recurrent neural networks}

Against the recurrent networks usually fit to behavioral data, the Discussion makes four comparisons:

\begin{ms}

PE signals are a well-established neural motif, observed across dopaminergic reward learning \citep{glimcher2011understanding}, predictive coding in perceptual inference, and motor control, making this mechanism a strong candidate for evidence integration in the brain. \textit{[\ldots]} Despite this, previous studies have rarely used neural network models to investigate dynamic PE-based evidence integration. Most existing models use Kalman-filter-style Bayesian updating \citep{millidge2021neural, adamiat2025spiking}, and have only been validated against synthetic tracking or regression tasks, never against real behavioral data. To our knowledge, our network is the first biologically-plausible, PE-based implementation that reproduces human behavior (especially individual differences) in evidence integration.

Four key features distinguish our SNN from the recurrent neural networks (RNN) that are typically fitted to human behavior \textit{[\ldots]} Our network is built from distinct populations that each perform specific functional computations, such as calculating discounted PE, maintaining the running value estimate, or tracking elapsed observations. This structure makes our network's predictions directly comparable to recordings from functionally or anatomically distinct cortical areas. An RNN's undifferentiated hidden layer, by contrast, mixes these computations together with no natural mapping onto specific brain regions or cell types, and requires post-hoc decomposition to identify the active representations and computations.

Many RNN architectures commonly used to fit behavioral choice data, such as gated recurrent units \citep{jian2025discovering}, rely on individual ``neurons'' that perform several nonlinear gating operations at once, a level of computational complexity implausible for a single biological neuron. Our network instead uses simple leaky integrate-and-fire neurons, widely regarded as a reasonable compromise between biological realism and computational tractability \citep{eliasmith2013build, gerstner2014neuronal, dayan2005theoretical}.

[Our] compositional approach to unified cognitive modelling can be used to build large-scale models spanning many distinct cognitive tasks from a shared set of reusable neural components \citep{choo2018spaun}. An RNN, by contrast, typically must be retrained from scratch for each new task, since nothing in its architecture encourages its representations to be generalizable across tasks.

Spiking noise in our network is an emergent, unavoidable consequence of representing a continuous value in a finite population of spiking neurons: population size, neural gain, and tuning-curve heterogeneity all combine to set its magnitude. Each of these parameters is a biologically meaningful, independently measurable quantity rather than a free parameter fit only to match behavior. An RNN's noise, if included at all, must instead be injected or fit as a free parameter with no such interpretation, making any match to human $\sigma$ dynamics an artifact of fitting rather than an emergent property of the network's representation.

While RNNs have achieved excellent fits to behavioral data in their own right, these features make our SNN a fundamentally different kind of model -- one built to generate anatomically- and mechanistically-grounded neural predictions, rather than simply to maximize behavioral fit.
\end{ms}

\begin{ms}
DPE belongs to a family of models that compress the influence of all past observations into a single estimate that is carried forward in time and updated via a weighted prediction error (PE; Eq.~\ref{eq:dpe_update}). These models differ primarily in how the weight on the newest observation, $\alpha(n)$, is computed. In the simplest case, $\alpha(n)$ is held constant, as in LeakyIntegrator and various RL algorithms such as TD(0) \citep{sutton2018reinforcement}. DPE is more flexible: $\alpha(n) = \alpha_0/n^\lambda$ changes with every observation, but only as a deterministic function of the observation count $n$ and the individually-fixed discounting rate $\lambda$. Adaptive-learning-rate models, including Kalman-filter-style Bayesian updating, instead compute $\alpha(n)$ online as a function of observed surprise or an evolving volatility estimate \citep{behrens2007learning, nassar2010approximately, yu2008sequential}: immediately after a detected change, the estimated uncertainty is high and the weight on new evidence is correspondingly large, then decays like $\approx 1/n$ as the new context is sampled. This is the same qualitative decay as DPE's $\alpha(n)$, but computed online from uncertainty rather than from a fixed schedule, suggesting a deeper correspondence between uncertainty-driven and schedule-driven accounts of dynamic weighting. Indeed, a neural signal consistent with this kind of reset and decay has been reported directly: a latent-context representation in orbitofrontal cortex shifts abruptly at inferred change points and then stabilizes as the new context is learned, mirroring the dynamics of the inferred learning rate itself \citep{nassar2019dissociable}. In every member of this family, bias is a byproduct of an otherwise generic attempt to track an uncertain, dynamic, or imprecisely-remembered world, not a pattern the model was built in advance to reproduce. For instance, DPE recovers the Bayes-optimal running mean at $\lambda=1$ and departs from it smoothly as $\lambda$ discounts older evidence more or less steeply. This kind of imprecise, approximate discounting with more observations is a reasonable computational constraint for a biological system, consistent with other work showing that weighted PE models can recreate both Bayesian-like behavior and the primacy and recency biases \citep{godara2025apparent}. The $\alpha(n)$ framework also extends well beyond volatility tracking: the same weighted-PE structure has been adapted to capture effects such as confirmation bias, by adjusting $\alpha(n)$ asymmetrically for confirming versus disconfirming evidence \citep{palminteri2022computational, palminteri2017confirmation}.
\end{ms}

We also agree that the ADM was underweighted in the original submission, and have addressed that by fitting its temporal weighting scheme as a baseline model on all four tasks (renamed PrimacyRecency, PR). Our PR model implements \citet{yoo2025people}'s Eq.~1 exactly,
\[
	w(o,n) = \left[1 - \left(1-\varepsilon_p^{\,o}\right) \left(1-\varepsilon_r^{\,n-o+1}\right)\right](1-\eta) + \eta,
\]
with $\eta$ fixed at 0.01, together with the weighted average over stored observations that forms the ADM's decision variable. We omit only the diffusion process, which our continuously reported estimates do not require, and we name the model for the weighting scheme it implements rather than for the diffusion model it was embedded in \citep{pooley2011understanding, galdo2022quest}. We found that PR is the strongest of the three baselines: it matches DPE on Binary Integration (0.4\% lower, $p$=0.40) and beats it on Continuous Integration (2.4\% lower, $p$=0.004). On the other two tasks DPE beats PR by 30.0\% and 9.4\%, and PR is the best-fitting model for no participant at all (Tables~\ref{tab:effect_sizes} and~\ref{tab:best_fit}, shown under C1). The passage the reviewer quotes, however, makes a claim about mechanism rather than fit, and there the ADM is on weaker ground. \citet{yoo2025people} note that the ADM can be rewritten as a running update of the current estimate, but specify that this holds ``when the weight on each IE is fixed and does not change over time'': precisely when it is not producing the temporal weighting that gives it its primacy and recency behavior. Once the weights change as evidence accumulates, the estimate must be recomputed from the full observation history.

As we discussed in section C3.1 above, competing mathematical models fail neural plausibility standards in different ways:
\begin{ms}
PR's weight for each past observation must be recomputed across the entire raw history whenever a new observation arrives, requiring an expanding memory of all previous observations alongside an expensive weighted summation -- the price of the modest fit advantage PR showed on Continuous Integration (Table~\ref{tab:effect_sizes}). Furthermore, its two free parameters are chosen specifically to let the fitted curve bend into whatever primacy or recency shape the data show; this mechanism serves as a flexible measurement of an already-observed bias, in the same spirit as other descriptive weighting methods that recover a temporal profile without proposing how it could be computed online \citep{anderson1965primacy, levi2018strategic, okazawa2018psychophysical}. Similarly, the Experience-Weighted Attraction (EWA) model \citep{camerer1999experience, ho2007selftuning} was developed for repeated strategic interaction, where a player faces other agents over a defined strategy space and can weigh the foregone payoff of unchosen strategies; it therefore requires maintaining a memory of each strategy's attraction and foregone payoff, as well as a parallel computation across alternatives to select a response. The same memory problem arises within a purely Bayesian approach: exact online inference about a changing environment requires maintaining a full posterior over every possible changepoint location \citep{adams2007bayesian}, an unbounded representation that is intractable for a biological system and is precisely why more tractable delta-rule approximations were developed \citep{wilson2013mixture}. It is telling that, to our knowledge, none of these models (PR, EWA, or exact Bayesian tracking) has actually been realized in a neural circuit. In contrast, DPE's running estimate requires neither unbounded memory nor involved calculations, and its biases emerge rather than being assumed. Being neurally implementable is therefore not a side benefit of DPE's simplicity, but the main reason it fits the criteria laid out above.
\end{ms}

In section C3.2 above, we also discussed how our SNN extends existing neural network models:
\begin{ms}
Four key features distinguish our SNN from the recurrent neural networks (RNN) that are typically fitted to human behavior: an anatomically interpretable architecture, biologically plausible single-neuron dynamics, a compositional structure that supports extension to new tasks, and inherent representational noise. Our network is built from distinct populations that each perform specific functional computations, such as calculating discounted PE, maintaining the running value estimate, or tracking elapsed observations. This structure makes our network's predictions directly comparable to recordings from functionally or anatomically distinct cortical areas. An RNN's undifferentiated hidden layer, by contrast, mixes these computations together with no natural mapping onto specific brain regions or cell types, and requires post-hoc decomposition to identify the active representations and computations. Many RNN architectures commonly used to fit behavioral choice data, such as gated recurrent units \citep{jian2025discovering}, rely on individual ``neurons'' that perform several nonlinear gating operations at once, a level of computational complexity implausible for a single biological neuron. Our network instead uses simple leaky integrate-and-fire neurons, widely regarded as a reasonable compromise between biological realism and computational tractability \citep{eliasmith2013build, gerstner2014neuronal, dayan2005theoretical}. Simple units also compose: the NEF's compositional approach to unified cognitive modelling can be used to build large-scale models spanning many distinct cognitive tasks from a shared set of reusable neural components \citep{choo2018spaun}. An RNN, by contrast, typically must be retrained from scratch for each new task, since nothing in its architecture encourages its representations to be generalizable across tasks. Spiking noise in our network is an emergent, unavoidable consequence of representing a continuous value in a finite population of spiking neurons: population size, neural gain, and tuning-curve heterogeneity all combine to set its magnitude. Each of these parameters is a biologically meaningful, independently measurable quantity rather than a free parameter fit only to match behavior. An RNN's noise, if included at all, must instead be injected or fit as a free parameter with no such interpretation, making any match to human $\sigma$ dynamics an artifact of fitting rather than an emergent property of the network's representation. While RNNs have achieved excellent fits to behavioral data in their own right, these features make our SNN a fundamentally different kind of model -- one built to generate anatomically- and mechanistically-grounded neural predictions, rather than simply to maximize behavioral fit.
\end{ms}

First, following a surprising observation, the size of a population's transient PE response predicts how quickly that response subsequently decays back to baseline (Fig.~\ref{fig:neural_main}A--C). Because $\alpha(n)$ scales the dynamic firing rate of error neurons that in turn discount value updates, individuals with higher discounting $\lambda$ will show progressively weaker error responses and smaller response updates as more evidence accumulates within a trial. The error population's representational capacity -- and thus how consistently it supports integration -- is shaped by biological factors such as the number of neurons recruited to represent the signal. This can be tested by measuring either spike-based or signal-based PE SNR (see Supplementary Text) and correlating it with $\sigma$ over repeated sequences.

The recurrent circuit maintains the running estimate in ongoing spiking activity that a delay-period perturbation can corrupt, while the synaptic circuit stores it in synaptic weights a transient current cannot reach. Having established a neural mechanism that jointly accounts for behavioral and neural signatures of evidence integration, we asked whether these conclusions depend on the specific circuit implementation of DPE, or whether they generalize to a different neural substrate. Our SNN implementation of DPE maintains its running estimate $V_n$ through persistent recurrent activity in the \textit{value} population, consistent with one leading account of how the brain sustains information in working memory \citep{wang2002probabilistic, wang2008decision}. An influential alternative hypothesis, however, proposes that working memory can instead be maintained by synaptic plasticity, without requiring sustained spiking to hold information between observations \citep{mongillo2008synaptic, stokes2015activity}. \begin{ms}
Our network is built from distinct populations that each perform specific functional computations, such as calculating discounted PE, maintaining the running value estimate, or tracking elapsed observations. This structure makes our network's predictions directly comparable to recordings from functionally or anatomically distinct cortical areas. An RNN's undifferentiated hidden layer, by contrast, mixes these computations together with no natural mapping onto specific brain regions or cell types, and requires post-hoc decomposition to identify the active representations and computations.

Many RNN architectures commonly used to fit behavioral choice data, such as gated recurrent units \citep{jian2025discovering}, rely on individual ``neurons'' that perform several nonlinear gating operations at once, a level of computational complexity implausible for a single biological neuron. Our network instead uses simple leaky integrate-and-fire neurons, widely regarded as a reasonable compromise between biological realism and computational tractability \citep{eliasmith2013build, gerstner2014neuronal, dayan2005theoretical}. Simple units also compose: the NEF's compositional approach to unified cognitive modelling can be used to build large-scale models spanning many distinct cognitive tasks from a shared set of reusable neural components \citep{choo2018spaun}. An RNN, by contrast, typically must be retrained from scratch for each new task, since nothing in its architecture encourages its representations to be generalizable across tasks.

Spiking noise in our network is an emergent, unavoidable consequence of representing a continuous value in a finite population of spiking neurons: population size, neural gain, and tuning-curve heterogeneity all combine to set its magnitude. Each of these parameters is a biologically meaningful, independently measurable quantity rather than a free parameter fit only to match behavior. An RNN's noise, if included at all, must instead be injected or fit as a free parameter with no such interpretation, making any match to human $\sigma$ dynamics an artifact of fitting rather than an emergent property of the network's representation. While RNNs have achieved excellent fits to behavioral data in their own right, these features make our SNN a fundamentally different kind of model -- one built to generate anatomically- and mechanistically-grounded neural predictions, rather than simply to maximize behavioral fit.
\end{ms}

\begin{ms}
We leveraged our SNN to generate four testable predictions relating neural activities to observable behavioral measures, then explained how each prediction arises from a specific biological mechanism. Importantly, all of these measures are either directly observable (population spiking activity recorded with high-temporal-resolution methods, response change and variability, etc.) or recoverable using well-established decoding techniques from the neural literature (population-vector decoding \citep{georgopoulos1986neuronal, wu2006bayesian}). Note that all four effects emerge from our particular circuit implementation, and are not a direct mathematical consequence of the DPE equation itself, making them network-specific, falsifiable predictions.

First, following a surprising observation, the size of a population's transient PE response predicts how quickly that response subsequently decays back to baseline (Fig.~\ref{fig:neural_main}A--C). Because $\alpha(n)$ scales both the magnitude of the error response and the speed with which it drives PE updates, individuals with a stronger baseline learning rate ($\alpha_0$) will both react more strongly and adapt faster to unexpected observations (outliers). This can be tested by decoding spikes from error-sensitive neurons during the cue period and correlating the maximum PE response to the subsequent PE decay before the next cue.

Second, the firing-rate decline of error-selective neurons within a trial predicts the decay rate of response updates (Fig.~\ref{fig:neural_main}D--F). Because $\alpha(n)$ scales the dynamic firing rate of error neurons that in turn discount value updates, individuals with higher discounting $\lambda$ will show progressively weaker error responses and smaller response updates as more evidence accumulates within a trial. This can be tested by measuring the activity of error-sensitive neurons after each observation and correlating it with the magnitude of response updates.

Third, the signal-to-noise ratio (SNR) in the decoded error signal predicts the resulting behavioral response variability $\sigma$ (Fig.~\ref{fig:neural_main}G--I). The error population's representational capacity -- and thus how consistently it supports integration -- is shaped by biological factors such as the number of neurons recruited to represent the signal. This can be tested by measuring either spike-based or signal-based PE SNR (see Supplementary Text) and correlating it with $\sigma$ over repeated sequences.

Fourth, perturbing the network during the intertrial interval (ITI) increases subsequent response error and variability in a dose-dependent way for networks that rely on activity-dependent working memory, but not for networks that rely on synaptic (activity-silent) working memory (Fig.~\ref{fig:synaptic_main}C--D). The recurrent circuit maintains the running estimate in ongoing spiking activity that a delay-period perturbation can corrupt, while the synaptic circuit stores it in synaptic weights a transient current cannot reach. This can be tested by applying a distractor task or non-invasive brain stimulation during the ITI and asking whether decoding accuracy recovers once the delay ends. More broadly, whether the brain relies on persistent, resource-intensive working memory or on more efficient, plasticity-based strategies is a question that extends well beyond evidence integration -- some have argued the brain shifts from the former to the latter as task demands increase \citep{collins2012much, westbrook2025striatal}. A similar synaptic-versus-working-memory comparison, in reward learning during foraging, reached a conclusion resembling ours: mechanisms relying on persistent activity were more sensitive to external perturbation than synaptic ones \citep{pereira2024brain}.
\end{ms}

\begin{ms}
Studying evidence integration through overall fit quality alone risks conflating models that reach similar predictions through different underlying processes; examining secondary behavioral signatures that emerge from a model's update mechanism provides a complementary test of whether it captures the underlying cognitive process, not merely its output \citep{palminteri2017falsification, wilson2019ten}. The concern generalizes beyond our paradigm: a model that minimizes error can still misrepresent qualitative features of the process that generated the data, including perseveration \citep{katahira2018statistical}, confirmation bias \citep{palminteri2017confirmation, palminteri2022computational}, and sequential choice-history effects \citep{yu2008sequential, zhang2014sequential}. Reporting $\Delta R$ and $\sigma$ alongside RMSE is how we identify where a model succeeds for the wrong reasons.

We take this point seriously, and it prompted a substantial revision of the relevant Discussion section. We do not dispute that EWA is a more general and more flexible framework for weighted updating, nor that dynamic weighting of past evidence has a long history; the manuscript no longer claims novelty on that basis, and situates DPE within that family instead (C3). We instead make the narrower claims that DPE captures human behavior and individual differences across four heterogeneous tasks and can be realized in a biologically plausible spiking circuit, unlike EWA and the other alternatives we discuss (C3).

Regarding the applicability of EWA to evidence integration, the reviewer is right that EWA has been applied in non-social as well as social settings, but the constraint we have in mind is not social versus non-social. EWA maintains an attraction and a foregone payoff for every strategy, so it needs a discrete set of alternatives to work at all. That requirement, together with the parallel computation across alternatives needed to select a response, is what makes EWA costly to implement in a circuit (C3). Our tasks present no such set: participants report a continuous estimate, with no alternatives to compare and nothing counterfactual to evaluate. So far as we are aware, EWA has not been applied to continuous sequential estimation of this kind, and doing so would require defining a strategy set and a payoff function where our tasks have neither. It is not clear that the flexibility and empirical coverage the reviewer describes would survive that reformulation, since the machinery responsible for them would have nothing to operate on.
